# Sicherheit

Keine Telefonnummern, Namen, E-Mail-Adressen, Chat-IDs, Bot-Tokens, App-Passwörter, Cookies, Browserprofile oder Datenbanken in Issues, Commits oder Fehlerberichte aufnehmen.

Sicherheitsprobleme bitte vertraulich über GitHubs „Private vulnerability reporting“ melden, sofern es für das Repository aktiviert ist.
